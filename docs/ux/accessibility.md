# Accessibility & Inclusive UX

## Target

WCAG 2.2 AA-oriented implementation.

## Requirements

- keyboard navigation for all interactive controls
- focus order follows visual order
- focus is never hidden behind sticky elements
- color is never the only signal
- form errors are announced and associated with fields
- tables have proper headers
- charts provide textual summaries
- motion can be reduced
- touch targets are appropriately sized
- dialogs trap focus and return focus correctly

## Analytics-specific accessibility

For every chart, provide:
- accessible title
- short summary
- data table or equivalent when practical
- explicit units
- date range
- filter state

## Usability testing

Test with keyboard-only navigation and at least one screen-reader workflow before release.

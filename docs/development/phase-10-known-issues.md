# Phase 10: Known Issues & Deferred Features

## Known Issues
- None. All 397 unit and integration tests and 100 evaluation benchmark cases pass deterministically.

## Deferred Features (Out of Scope for Phase 10)
- **Arbitrary Many-to-Many Joins without Bridge Tables**: Deliberately prevented to protect against uncontrolled row explosion.
- **RAG / Vector Databases**: Out of scope (Phase 10 adheres to structured tabular federation).
- **Multi-Agent Swarm Loops**: Out of scope.
- **External Real-time Live Connectors (Snowflake/BigQuery)**: Out of scope.

# Phase 7 — Known Issues & Limitations

## Current Status
All automated unit, integration, and evaluation suites are passing (173 / 173 tests passing).

## Known Limitations
1. **Multi-Series Grouped Bar / Multi-Line Charts**:
   - The current engine supports single-series and basic grouped series charts; advanced nested grouping (e.g., stacked percent bars) will be expanded in future releases.
2. **Chart Annotations**:
   - Custom freehand user annotations on charts are not yet supported.
3. **Automated Dashboard Generation**:
   - Multi-chart canvas layouts and automated dashboard generation are deferred to Phase 8.

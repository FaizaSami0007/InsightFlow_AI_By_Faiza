# Phase 9: Export Architecture & Engine Specification

## 1. Architectural Principles

In InsightFlow AI, the export pipeline adheres strictly to the single source of truth principle:
- **No Generative AI in Export Rendering:** AI is strictly restricted to high-level analysis intent, query generation, and dashboard layout planning. Under no circumstances does AI generate arbitrary HTML, JavaScript, CSS, or executable PDF code.
- **Specification-Driven Determinism:** All exports (PDF, PNG, CSV, JSON, and Print) are rendered deterministically directly from the validated `DashboardSpecification`, widget configurations, and validated DuckDB analytical result rows.
- **Security & Multi-Tenant Boundary:** Export generation enforces user authentication, dashboard ownership, dataset access policies, and path sanitization.

```
Dashboard State (Validated Specification & Analytics)
   │
   ▼
Export Engine (`app/exports/engine.py`)
   ├── PDF Generator (ReportLab Platypus Engine)
   ├── PNG Generator (Pillow High-Resolution Canvas)
   ├── CSV Generator (Tabular Result Formatter)
   ├── JSON Generator (Specification Serializer)
   └── Print Engine (CSS Paged Media `@media print`)
   │
   ▼
Secure Storage & Stream Delivery (`/api/v1/exports/{id}/download`)
```

## 2. Supported Export Modalities

| Format | Engine | Target Resolution / Size | Primary Use Case |
| :--- | :--- | :--- | :--- |
| **PDF** | ReportLab Platypus | A4 / Letter, Portrait / Landscape | Executive presentation, formal reports, archival |
| **PNG** | Pillow (PIL) | 1600x1200 high-DPI canvas | Slide decks, Slack/email sharing, preview cards |
| **CSV** | Python CSV Writer | Standard UTF-8 CSV | Spreadsheets, secondary data analysis |
| **JSON** | Pydantic JSON Encoder | Validated JSON spec | Backup, dashboard migrations, API consumers |
| **Print** | CSS `@media print` | Browser Paged Media | Direct paper printing & browser native PDF |

---

## 3. Resource Bounds & Safeguards

To prevent Denial of Service (DoS) and memory exhaustion, the export pipeline enforces the following bounds:

- `MAX_EXPORT_ROWS`: 100,000 rows
- `MAX_EXPORT_WIDGETS`: 50 widgets
- `MAX_EXPORT_FILE_SIZE`: 50 MB
- `MAX_EXPORT_EXECUTION_TIME`: 30 seconds
- **Filename Sanitization:** All export filenames undergo strict regex normalization to alphanumeric, hyphen, and underscore characters (`[a-zA-Z0-9_\-]+`) to eliminate path traversal vulnerabilities (`../`, `\`, null bytes).

## 4. Metadata & Provenance Audit Trail

Every export generated by the engine records:
- `export_id`: UUIDv4 unique identifier
- `dashboard_id`: Associated dashboard
- `user_id`: Authenticated requester
- `dataset_id` & `dataset_version_id`: Data lineage source
- `format`: Export format string (`pdf`, `png`, `csv`, `json`)
- `status`: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `EXPIRED`
- `filter_snapshot`: Active filter values applied at time of export
- `created_at` & `expires_at`: Generation and retention timestamps

# Privacy & Retention

## Default principle

Collect the minimum user/account data needed for the service.

## Dataset retention

Retention is configurable by environment and product policy. The system must distinguish active, archived, and deleted data.

## AI provider boundary

Only the minimum context required for an AI request should be sent to an external provider. Sensitive fields should be masked or excluded when possible.

## User controls

Users should be able to:
- delete datasets
- export relevant data
- view dataset ownership
- understand when AI processing occurs

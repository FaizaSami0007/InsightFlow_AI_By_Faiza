# Changelog

All notable changes to InsightFlow AI will be documented in this file.

## [1.0.0] - 2026-10-06

### Added
- **Phase 01–04:** Foundation, JWT authentication, Argon2/Bcrypt hashing, chunked CSV/Parquet dataset ingestion, Polars profiling engine, and DuckDB deterministic analytics engine.
- **Phase 05–08:** Autonomous AI orchestration (Gemini 2.0 Flash), conversational BI with multi-turn context memory, chart recommendation engine (Apache ECharts/Vega), and dynamic grid dashboard layout planner.
- **Phase 09–10:** Executive PDF/CSV report generation, signed share tokens, and multi-dataset cross-source federation with DuckDB joins.
- **Phase 11–13:** Predictive time-series forecasting (ARIMA, Exponential Smoothing), multi-method anomaly detection (Z-Score, IQR), and what-if decision scenario simulations.
- **Phase 14–16:** Knowledge Intelligence RAG with heading-aware chunking, hybrid vector search, 9-agent DAG supervisor orchestration, and MLOps drift monitoring.
- **Phase 17–19:** Enterprise connectors (PostgreSQL, MySQL, Snowflake, BigQuery, S3, Salesforce), zero-trust security hardening (PromptGuard, ExportGuard, RBAC), and production observability with Prometheus metrics and SLO monitors.
- **Phase 20:** Final Product QA, 10 Critical User Journeys (A–J) end-to-end release verification suite, synthetic sales demo dataset, and full documentation suite.

### Security
- Added `PromptGuard` adversarial prompt injection defense and system probe interceptor.
- Added `ExportGuard` spreadsheet CSV formula injection escape.
- Added zero-trust multi-tenant isolation across all ORM models and cache stores.
- Added OWASP secure response headers middleware.
